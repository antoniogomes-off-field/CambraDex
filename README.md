# Cambra GO — CambraDex

Protótipo de um jogo de criaturas inspirado em Vale de Cambra, com uma CambraDex de 151 criaturas (incluindo lendárias nas Raids).

## Como jogar
Abre o `index.html` num navegador moderno. Mantém a pasta `assets` ao lado do `index.html`.

Se o GitHub Pages estiver ativo, o jogo pode ser aberto diretamente no endereço do Pages deste repositório.

## Instalar no telemóvel
O Cambra GO pode ser instalado como uma aplicação:

- **Android (Chrome):** abre https://antoniogomes-off-field.github.io/CambraDex/, toca no menu ⋮ e escolhe **Instalar aplicação** ou **Adicionar ao ecrã principal**.
- **iPhone (Safari):** abre o mesmo link, toca em **Partilhar** e escolhe **Adicionar ao ecrã principal**.

Depois de aberto uma vez com internet, o jogo funciona sem ligação.

## Estrutura
- `index.html` — o protótipo.
- `assets/creatures/001.webp` a `151.webp` — ilustrações das criaturas, pelo número da grelha.
- `manifest.webmanifest`, `sw.js` e `icons/` — instalação como aplicação e modo offline.
- `sample.jpg` — imagem original do poster.
